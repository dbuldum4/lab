# Agent preferences

## Writing

- Follow William Zinsser's four principles of quality writing: clarity, simplicity, brevity, and humanity.
- Apply these principles to conversation, documentation, plans, reviews, and other written artifacts.

## Code review

- When asked to review a PR, branch, or local changes: report findings **in the conversation only**.
- Do **not** post PENDING (or submitted) GitHub PR reviews.
- Do **not** create inline review comments via the GitHub API unless the user explicitly asks to post them.

## GitHub CLI

- Escalate `gh` CLI commands outside the sandbox when needed. A sandboxed `gh` command can appear to have an authentication error even when authentication is valid.
